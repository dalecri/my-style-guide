PERSONAL DESIGN SYSTEM — V3, INTERACTIVE

Quiet by default.
Precious in small doses.

Not a Lamplight style sheet — a personal system, distilled from Lamplight because it's the clearest expression of the taste. Apply this to Wordnest, Keepsake, or whatever's next: same palette, type, and motion rules, different content and mood. Every control below is live — press it, don't just read about it.

08

Motion spec

Every transition above, named — reuse these values rather than inventing new timing per project.

◐
Theme crossfade — 400ms, ease-in-out
Background, accent, and orb colors fade together. No slide, no scale — a pure color transition, like light changing in a room.
○
Focus word pulse — 650ms, one-shot
Scale 1→1.16 with a soft text-shadow bloom, settling back to 1. Runs once per word, never loops or repeats mid-word.
◇
Control press — 120ms, scale(0.96–0.97)
Every tappable pill, button, and transport control compresses slightly on press. It's the only "snappy" motion in the system — feedback needs to feel immediate.
⬭
Toggle switch — 400ms, knob slide + shape morph
The capsule knob slides across and its corners un-round asymmetrically (rounded on the leading edge, square on the trailing one) as it moves. Color crossfades from muted to accent at the same time — no separate color-then-move sequencing.
▭
Panel / modal open — 280ms, translateY(16px)→0 + fade
Sheets rise gently from below rather than appearing instantly. Ease-in-out throughout, no bounce or overshoot.
◒
Reduced motion — crossfade only
With prefers-reduced-motion set, every animation above collapses to an instant or near-instant state change. Never disable the feedback entirely — just remove the movement.

15

Principles

◐
Pixel art illustrates, it doesn't build
The moon, sun, lamp, and bonfire are small pixel-art scenes — not the material the buttons and cards are made of.
○
Rounded and soft, not notched
Every container and control gets a real border-radius. Hard edges read as loud — this system stays quiet.
◇
One accent leads, contextually
The accent shifts with mode rather than staying fixed brand-wide. It's mood lighting, not a logo color.
▭
Let the content be the color
The UI chrome stays low-contrast and dark. Saturated color belongs to content — book spines, artwork — not to buttons and panels.
16

Fixed vs. flexible

The point of a personal system isn't to make every app look identical — it's that a stranger could see three of your apps side by side and know they came from the same hand. These are the load-bearing rules versus the room each app has to move.

Fixed — every app
  • Void/surface/muted neutrals — the dark soft-purple base never changes
  • Rounded, soft shapes — no notched or hard-edged UI chrome
  • Space Mono for UI + body; pixel type stays a small accent
  • Motion timing and easing (280ms panels, 650ms one-shot pulses, no bounce)
  • One accent leading per screen, never several fighting
Flexible — per app
  • Which accent hue is "home base" (moon/lamp/dawn are Lamplight's — a new app can own a different hue in the same family)
  • What the pixel illustration actually depicts (moon and lamp are reading-specific; a task app might use different small motifs)
  • Layout structure and information density (a flashcard app isn't a shelf-plus-reader)
  • Where the "loud" saturated moment lives (book spines here; could be cards, tiles, tags elsewhere)
17

Do / Don't

Do
  • Dark, soft-purple grounds by default
  • Rounded pills and circles for controls
  • Small pixel illustrations as focal moments
  • One contextual accent per screen
  • 280–650ms eased transitions, nothing instant or bouncy
Don't
  • Notched corners or hard flat borders on UI chrome
  • Pixel type or pixel borders on every element
  • Warm cream as the default ground
  • Multiple accents fighting on one screen
  • Bounce, overshoot, or spring easing anywhere
